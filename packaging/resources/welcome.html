AudioRoute installation

Route selected Mac applications and audio interfaces into named virtual microphones and outputs.

This installer adds AudioRoute to Applications, the audioroute command to /usr/local/bin, and its virtual audio driver and transport service. macOS will ask for administrator approval.

Install while signed in to the Mac account that will use AudioRoute. The current release supports one routing account per Mac; other accounts cannot access its routing audio. macOS 14.2 or later is required on Apple silicon or Intel.

Installation does not restart audio services. A Mac restart is recommended after installing or updating the driver. Save any ongoing recording before restarting.
